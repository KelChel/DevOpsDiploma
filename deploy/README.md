# Deploy

DevOps-конфигурация проекта находится в корне репозитория и в `.github/workflows`.

## Контейнерная поставка

- `backend/Dockerfile` собирает FastAPI-сервис, устанавливает Python-зависимости, применяет миграции Alembic и запускает Uvicorn.
- `frontend/Dockerfile` собирает окружение Vite/React и запускает dev-сервер для учебного стенда.
- `docker-compose.yml` поднимает PostgreSQL, backend и frontend одной командой.

## CI/CD

Workflow: `.github/workflows/ci.yml`.

Pipeline выполняет:

- установку backend-зависимостей;
- базовую проверку Python-кода;
- проверку миграций;
- backend-тесты;
- frontend-сборку;
- сборку Docker-образов;
- запуск Docker Compose в тестовом режиме;
- smoke-тест `GET /health`.

## Секреты и окружения

Реальные секреты должны храниться только в защищенных переменных CI/CD или локальном `.env`, который не попадает в Git. В workflow не записываются реальные токены, пароли и ключи. Для уведомлений в CI используется `NOTIFICATION_PROVIDER=mock`.

## Откат

Для учебного стенда откат выполняется возвратом к предыдущему успешному commit/tag и повторным запуском pipeline. Для production-подхода рекомендуется публиковать Docker-образы с версионированными тегами и переключать окружение на предыдущий тег при неуспешной поставке.
