# Seed-данные

Итерация 2 создает демонстрационных пользователей через миграцию `202604260002_users_roles_auth`.

| Логин | Пароль | Роль |
|---|---|---|
| `employee` | `password` | Сотрудник |
| `executor` | `password` | Исполнитель |
| `admin` | `password` | Администратор |
| `manager` | `password` | Руководитель |

Пароли сохранены в базе только в виде bcrypt-хешей.

Итерация 7 добавляет демонстрационные заявки через миграцию `202604260005_sla_reports_seed_data`.

| Назначение | Содержание |
|---|---|
| Просрочка SLA | Критическая заявка в работе с истекшим сроком выполнения. |
| Нагрузка исполнителя | Назначенная заявка с высоким приоритетом. |
| Закрытый сценарий | Закрытая заявка для статистики по выполненным обращениям. |

Тексты демонстрационных заявок не содержат медицинских данных пациентов.
