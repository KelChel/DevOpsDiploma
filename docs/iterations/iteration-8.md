## Критерии готовности

- Документация позволяет запустить проект без устных пояснений.
- Основные API, схемы и модель данных описаны.
- DevOps-процесс описан как часть жизненного цикла продукта.
- Требования связаны с реализацией, тестами и критериями приемки.
- Ограничения по медицинским данным, секретам, логам, дампам и очистке базы зафиксированы.
