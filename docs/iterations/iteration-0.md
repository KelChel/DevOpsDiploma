## Границы

Проект является учебным прототипом и не является медицинской информационной системой.

В системе запрещено хранение медицинских данных пациентов. Запрет распространяется на заявки, комментарии, логи, уведомления, seed-данные, тестовые фикстуры и дампы базы данных.
