# Риски и меры снижения

| Риск | Вероятность | Влияние | Меры снижения |
|---|---|---|---|
| Попадание медицинских данных пациентов в заявки или комментарии | Средняя | Высокое | Предупреждение в интерфейсе, политика данных, запрет таких данных в seed-данных, логах и дампах. |
| Попадание секретов в репозиторий | Средняя | Высокое | `.env` вне Git, `.env.example` только с шаблонами, секреты CI через GitHub Secrets, тест маскирования логов. |
| Ошибка ролевого доступа | Средняя | Высокое | Backend-проверки ролей, security-тесты, матрица ролей и прав. |
| Невоспроизводимый локальный запуск | Средняя | Среднее | Docker Compose, миграции Alembic, README с командами запуска и сброса базы. |
| Расхождение схемы БД и кода | Средняя | Среднее | Проверка `alembic upgrade head` в CI и integration-тест миграций. |
| Поломка жизненного цикла заявки при изменениях | Средняя | Высокое | Unit-тест переходов статусов и API-тест полного сценария. |
| Недоступность внешнего MAX API на демонстрации | Низкая | Среднее | Mock-провайдер уведомлений по умолчанию, реальный адаптер заменяемый и не обязателен для MVP. |
| Неполные демонстрационные данные | Средняя | Низкое | Seed-заявки для отчетов и SLA, команда сброса базы до известного состояния. |
| Frontend не собирается после изменений | Средняя | Среднее | `npm run build` локально и в CI. |
| Документация устаревает относительно кода | Средняя | Среднее | Отдельные итерационные отчеты, трассируемость требований, обновление README при изменении API и сценариев. |
