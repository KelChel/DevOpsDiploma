# Границы MVP

## Рабочее название

DevOps Ticket System.

## Назначение

Система внутренних заявок медицинской организации для технических, организационных и сервисных обращений сотрудников.

## Входит в MVP

- Пользователи и роли: сотрудник, исполнитель, администратор, руководитель.
- Авторизация через JWT.
- Создание заявки сотрудником.
- Просмотр своих заявок сотрудником.
- Просмотр всех заявок администратором.
- Просмотр назначенных заявок исполнителем.
- Назначение исполнителя администратором.
- Изменение статусов заявки по разрешенному жизненному циклу.
- История изменений заявки.
- Комментарии.
- Mock/MAX-уведомления.
- Запуск через Docker Compose.
- Endpoint `/health`.
- Автоматизированные тесты ключевых сценариев.
- CI/CD-пайплайн проверки, сборки и smoke-теста.

## Не входит в обязательный MVP

- Полноценный кабинет руководителя.
- Отчеты и статистика.
- SLA и просрочки.
- UI/API административного управления пользователями, ролями и справочниками.
- Создание заявок через MAX-бота.
- Добавление комментариев через MAX.
- Реальная эксплуатационная обработка медицинских данных.

## Демонстрационный плюс

- Панель статистики.
- Расчет SLA.
- Seed-данные для повторяемой демонстрации.
- OpenAPI-документация основных endpoint.
- Расширенные security-тесты.
- Структурированные логи backend.

## Запрет медицинских данных

Система не является медицинской ИС. В заявках, комментариях, логах, уведомлениях, seed-данных и дампах запрещены персональные и медицинские данные пациентов.
