# Журнал DevOps-метрик

## Назначение

Журнал фиксирует измеримые результаты учебного процесса поставки. Значения используются как артефакт для магистерской работы и как контроль повторяемости сборки.

## Метрики для последующих запусков

| Метрика | Как фиксировать |
|---|---|
| Время backend-тестов | По выводу `pytest` или GitHub Actions. |
| Количество тестов | По строке результата `pytest`, например `22 passed`. |
| Время frontend-сборки | По шагу `Build frontend` в CI. |
| Факт сборки Docker-образов | Успешность шага `docker compose build`. |
| Результат smoke-теста | HTTP 200 и JSON `{"status": "ok", "database": "ok"}`. |
| Найденные ошибки | Количество дефектов, выявленных тестами или ручной приемкой. |
| Исправленные ошибки | Количество дефектов, исправленных в рамках итерации. |
