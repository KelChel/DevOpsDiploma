# Политика данных и секретов

## Данные пациентов

Проект не хранит и не обрабатывает медицинские данные пациентов. Запрещено добавлять такие данные в:

- заявки;
- комментарии;
- историю действий;
- уведомления;
- логи;
- seed-данные;
- тестовые фикстуры;
- дампы базы данных;
- скриншоты для демонстрации.

## Секреты

Реальные секреты не должны попадать в репозиторий.

К секретам относятся:

- JWT secret;
- пароли баз данных;
- токены MAX;
- ключи API;
- приватные ключи и сертификаты;
- production URL с учетными данными.

Для локального запуска используется `.env`, созданный на основе `.env.example`. Файл `.env` игнорируется Git.

## Учебное хранение и очистка

Правила очистки демонстрационной базы, ограничения резервных копий и запрет попадания секретов в дампы описаны в `docs/security/storage-retention.md`.
